# \## About the Project

# 

# Shakshya AI is a frontend prototype designed to support AICTE Extension of Approval (EoA) application readiness review. It helps reviewers identify potential document issues and organize evidence for human review.

# 

# \## Key Features

# 

# \- OCR-based document text extraction

# \- Missing document detection

# \- Cross-document mismatch identification

# \- Evidence-based compliance reporting

# \- Human-in-the-loop review workflow

# 

# \## Technology Stack

# 

# \- React

# \- TypeScript

# \- Vite

# \- Tesseract.js

# \- PDF.js

# 

# \## Run Locally

# 

# \*\*Prerequisite:\*\* Node.js and npm.

# 

# ```bash

# npm install --legacy-peer-deps

# npm run dev

# ```

#

#

# npm run lint

# npm run build

# ```

# 

# \## Privacy and Limitations

# 

# OCR processing runs locally in the browser. This repository does not connect to an issuer API or application backend. Automated findings are preliminary and do not constitute issuer verification, proof of fraud, or an official approval decision.
